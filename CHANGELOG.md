# Changelog

## 0.4.0 — 2026-11-24

Early open-source, local-first release.

- Added Ashby startup feeds and optional role-based Tavily discovery.
- Added posting-link import, source-linked company checks and recruiter/employee leads.
- Preserved uncertain availability, contact activity and publication dates explicitly.
- Improved fresher screening, current-lead filtering and duplicate handling.
- Added private search-key storage, six-hour caching and a local monthly request cap.
- Added contributor templates, CI checks, architecture/privacy documentation and empty-install verification.

Known limits: selected sources only; indexed leads require review; no background Gmail OAuth, automatic applications, or automatic LinkedIn outreach. Hosted multi-user service is not included.
