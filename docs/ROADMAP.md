# Roadmap

This is an early open-source release. Priorities are ordered by job-seeker impact, not promised delivery dates.

1. **Fresh relevant openings:** expand documented employer sources, verify indexed postings, measure false positives and make expiry handling clearer.
2. **Better evidence:** improve employer identity matching and contact affiliation checks; show gaps when current activity cannot be verified.
3. **Cost visibility:** show local request counts and provider balance separately; keep search optional and reuse company results.
4. **Tracking automation:** opt-in Gmail OAuth with minimal scopes, reviewable event matching, revocation and background sync.
5. **Distribution:** test more operating systems, improve first-run onboarding and evaluate multi-user hosting with per-user data isolation and budgets.

Contributions and alternative ideas are welcome. Start with an issue describing the user problem and a small verifiable slice. Source integrations need documented permission/access and truthful date semantics. Automated outreach and guaranteed scam detection are outside the current scope.
